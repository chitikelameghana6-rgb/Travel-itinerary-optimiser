## 📌 About the Project

Travel Itinerary Optimizer is a route optimization application that finds a cost-efficient itinerary for visiting multiple cities while respecting a maximum trip duration.

## 🧠 Algorithms Used

- Traveling Salesperson Problem (TSP)
- Dynamic Programming
- Branch and Bound
